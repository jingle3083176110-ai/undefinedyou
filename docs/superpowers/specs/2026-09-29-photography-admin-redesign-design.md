# 摄影后台 A 方案改造设计

## 目标

把当前摄影后台改造成一个适合长期管理照片的工作台：信息层级清楚、字体不遮挡、上传和批量操作容易发现，且不改变现有 Supabase 数据结构和 API 能力。

## 视觉方向

采用“编辑工作台 / 摄影档案室”风格：米白背景、深墨色文字、橄榄绿作为唯一强调色。标题使用现有项目的衬线字体体系，正文和控件使用易读的无衬线字体。所有控件保留明显焦点环、悬停和按下状态。

## 页面结构

### 侧栏

桌面端固定左侧导航，包含：摄影总览、全部照片、上传照片、主题、Workshop、批量操作、设置。当前栏目有明确选中态。移动端侧栏变为可展开抽屉。

### 顶部栏

顶部只保留当前页面标题、全局搜索、上传照片主按钮和账号菜单。筛选控件不与顶部操作混排。

### 总览和照片库

总览显示全部照片、已发布、已下架和最近上传四个统计指标。照片库使用响应式网格；每张卡片显示缩略图、Photo ID、地点、所属集合和发布状态，并提供编辑、上架 / 下架、删除操作。卡片操作按钮有足够点击面积，不使用拥挤的纯文字串联。

### 上传工作区

上传页提供拖拽区域和文件选择器，支持单张、多张以及文件夹选择。文件进入上传队列后显示文件名、缩略图、处理状态和失败重试。主题 / Workshop、发布状态等共用元数据放在队列上方，可应用到全部待上传文件。上传仍通过现有 POST `/api/admin/photos` 接口完成，图片处理继续由服务端负责。

### 编辑抽屉

点击照片卡片的编辑后打开右侧抽屉，不离开照片列表。抽屉左侧显示预览，右侧编辑标题、Alt 文本、地点、日期、比例、中文 / 英文说明、发布状态和多个主题 / Workshop。底部固定保存与取消操作，保存失败显示在抽屉内；有未保存修改时关闭会提示。

### 批量操作

照片卡片支持选择框，批量工具栏只在有选择时出现。支持批量上架、下架和设置集合，并显示已选择数量。批量请求逐项调用现有 PATCH 接口，失败项保留在选择列表并显示错误。

## 响应式与可访问性

- 桌面端使用侧栏 + 主工作区，窄屏改为抽屉导航和单列卡片。
- 所有输入都有可见标签或 aria-label。
- 所有按钮具有 hover、focus-visible、disabled 状态。
- 上传、加载、空列表、失败和成功均有明确状态。
- 不使用固定高度裁切标题，避免中文字体遮挡。

## 数据与接口约束

继续使用现有照片和集合 API，不直接在浏览器暴露私有原图。公开预览继续使用 `src`，原图保持私有存储。编辑和批量操作必须保留现有 collectionIds，避免误删集合关联。

## 验收标准

1. 页面标题、按钮和筛选器在桌面与窄屏均不重叠。
2. 用户能从任意页面在两步内进入上传流程。
3. 用户能看到上传队列、失败状态和重试入口。
4. 用户能编辑完整照片元数据并保留多个集合关联。
5. 用户能批量上架、下架和设置集合。
6. 现有 API 测试和生产构建继续通过。

近日，关于秋晚抢票网站的事情在学校论坛上引起热议。

简单来说，学生事务处的老师用 AI 做了一个抢票网站给学生们使用。然而，网站制作粗糙，所提供的网址处于“裸奔”状态，被部分浏览器视作危险网址而禁止访问；抢票时间访问人数过多，又造成服务器崩溃。许多学生因此无法正常参与抢票流程而错失门票，引起众多学生不满。

我无意在此评价此事。我只是从中看出一种现象：Vibe Coding 的滥用。

## 何为滥用？

在我看来，滥用并不是单单指大量地使用，而是不合理、不规范、无监管、无益处地使用。

老师们的初心当然是好的，希望能通过一个网站流程化整个抢票过程，避免出现之前用问卷星抢票造成的难管理、难核销问题。这次的网站看上去有模有样，我估计在小范围使用时效果应当也不错；但真正到实际应用时却出现了灾难性的问题。

这正正体现了 Vibe Coding 产品的一大特性：虚假性。

Vibe Coding 的强大之处在于，它让完全非相关专业的人可以通过自然语言进行编程。但正是因为这种便利性，让制作者无法有效地对产出的产品进行审查。表面看上去近乎完美的产品背后，也许隐藏着种种不稳定的因子，需要专业人士验收和调整，在全面打磨之后才能真正投入使用。

最细思极恐的是：学生事务处是一个有学校管理的机构，主要负责人是老师；学校也有专门的技术管理部门和网络安全相关从业人员。但这样一个漏洞百出的网站，却在如此重要的场合被水灵灵地端了出来。

为什么抛弃了历年使用的稳定抢票方式？为什么不寻求专业人士帮助？为什么没有考虑事情的可能后果，就急急忙忙更换抢票方式，甚至没有邮件通知？

我想，只有一个原因：对 AI、对 Vibe Coding 的绝对自信。

老师们在做出这个产品之后，受限于专业能力，仅仅对网站的表面内容和小范围试用进行了检验。对 AI 产品的盲目自信，让他们不再向专业部门寻求帮助，将其当作成熟的网站应用于全校上万人的抢票活动。

此次失误仅仅造成学生的不满与批评。试问：如果以这种方式将 Vibe Coding 应用于教务、财务、安全等方面，将会造成多么严重的后果？

这种情形显然不止发生于学校行政体制内。个人工作者、企业、国家机构必然也会在 AGI 时代面临如何利用好 Vibe Coding 的问题。如何对 Vibe Coding 产品进行监管、检测；如何增强 AI 产品的效益，必然是当下的重要议题。

作为计算机学生，我肯定也会利用 Vibe Coding 制作产品。但除了制作产品本身，更应当思考的或许是：如何检验一个产品是否合格，如何确保一个产品能应用到实际，如何维护好一个产品。

或许“实践是检验真理的唯一标准”这句话在当今时代还要再深一步扩展：

> “实践”不能只是成功循环一次，或在某个情况下成功循环就算作“实践”，而是在不同的环境和场景中尽可能不断地测试和检验；所谓的“真理”也不一定就是“真理”，往往要对每一个举措的结果做好充足的备案，去应对可能出现的结果。
